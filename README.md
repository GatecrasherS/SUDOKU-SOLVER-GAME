# SUDOKU-SOLVER-GAME
Automated Sudoku Solver &amp; Generator in C++

## KEY FEATURES :
* **Engineered a terminal-based Sudoku tool** using Object-Oriented Programming (OOP) principles to handle validation and user inputs.
* **Implemented a custom backtracking algorithm** that systematically solves any valid 9x9 Sudoku puzzle matrix.
* **Utilized efficient memory layout frameworks** to prevent data leakage across recursive solver stack frames.
## CORE TECHNICAL CONCEPTS EXPLORED
* Backtracking Algorithm
* OOP fundamnetals
* Recursive Function to Promote Reusability

## GAMEPLAY
1. Run the program execution command
2. Input the correct Sudoku grid
3. Solved Sudoku grid is displayed
